# 스크린샷 폴더

`my_environment.md`의 "증빙 스크린샷" 섹션에 들어갈 이미지 두 장을 여기에 저장합니다.

## 필요한 파일

| 파일명 | 무엇을 찍나 | 어떻게 찍나 |
|--------|------------|------------|
| `ai-chat.png` | Claude 사이드바에서 환경 관련 질문/답변이 보이는 화면 | VS Code 우측 Claude 사이드바에 대화 내용이 보이는 상태로 `Win + Shift + S` (캡처 도구) |
| `vscode-workspace.png` | 좌측 파일트리 + 가운데 미리보기 + 우측 Claude가 모두 보이는 전체 화면 | VS Code를 풀스크린(`F11`)으로 한 뒤 `Win + Shift + S` 또는 `PrintScreen` |

## 캡처 팁

- **창 전체 캡처:** `Alt + PrintScreen` → 클립보드에 활성 창만 복사됨
- **영역 캡처:** `Win + Shift + S` → 마우스로 영역 선택
- 캡처한 이미지를 이 폴더(`Q1/screenshots/`)에 위 파일명으로 저장하면 `my_environment.md`에서 자동으로 표시됩니다.

## 파일 추가 후

`my_environment.md`를 미리보기(`Ctrl+Shift+V`)로 열면 6번 섹션에 이미지가 들어가 있는 걸 확인할 수 있어요.
